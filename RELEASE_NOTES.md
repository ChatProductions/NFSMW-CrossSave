# NFSMW CrossSave v1.0.0

Windows GUI save converter for Need for Speed: Most Wanted (2005).

## Supported operations

- GameCube (USA) to PC
- PC to GameCube (USA)
- Experimental GameCube edition conversion: GOWE69, GOWP69, GOWD69, GOWF69, GOWJ13

## Compatibility

PC and USA GameCube conversions have been tested in-game on selected career saves.
Other regions have only passed offline structure and checksum tests. Always back up
your save files and Dolphin memory card before testing a conversion.

## Windows

Download the portable EXE from GitHub Releases once the automated build finishes.
If the release is not available, use the GitHub Actions build artifact or build
locally with `Build Windows EXE.bat`.
